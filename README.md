# CalWall — 잠금 화면 캘린더

Layered(중단된 앱)를 대체하려고 만든 개인용 앱. **잠금 화면에만** 적용되고, 매일 새벽에 자동으로 다시 그린다.

## 설치
1. [Releases](https://github.com/judy1467/calwall/releases) 에서 최신 `CalWall-x.y.z.apk` 를 내려받는다
2. 휴대폰에서 "출처를 알 수 없는 앱" 설치를 허용하고 APK를 연다 (Android 12 이상)
3. 첫 실행 시 **캘린더 권한**을 허용 → `사진 선택` → `잠금 화면에 적용`

> 업데이트는 같은 서명 키로 만든 APK만 덮어쓸 수 있습니다. 서명 키(`signing/calwall.keystore`)는 저장소에 올리지 않습니다.

## 기능
- 사용자가 고른 사진 위에 캘린더를 얹는다 (사진 선택: `ACTION_OPEN_DOCUMENT`, 권한은 영구 보존)
- 이번 주부터 4주치를 **주 단위 스트립**으로 표시, 일정은 기간만큼 늘어나는 색 바
- 오늘 날짜 강조, 일/토 색 구분, 테마(라이트/다크), 강조색 3종
- **매일 00:05 정확 알람**으로 자동 갱신 (기기 재부팅·시간 변경에도 재예약)
- 6시간 주기 JobScheduler(persisted)로 놓친 알람을 보정
- 적용 대상: 기본은 `FLAG_LOCK`(잠금 화면). `선택한 사진을 홈 화면에 적용` 버튼은 **사진만** `FLAG_SYSTEM`에 넣는다 (잠금 해제 시 같은 사진이 이어지도록)
- 잠금 화면에는 시계 가독성을 위해 상단에 옅은 어두운 그라데이션을 넣는다

## 구조
```
AlarmManager(00:05, exact)  ─┐
JobScheduler(6h, persisted) ─┼─> AlarmRx / TickJob ─> Applier ─> WallpaperRenderer ─> WallpaperManager(FLAG_LOCK)
BOOT_COMPLETED / DATE_CHANGED┘
```
- 렌더링은 전부 `android.graphics` 캔버스 (외부 라이브러리 없음, APK 약 45KB)
- 캔버스는 시스템 wallpaper 버퍼(2448×2448)에 맞추고, 화면 비율(1248×1972)만큼의 세로 컬럼에 내용을 배치한다.
  시스템이 버퍼의 중앙 세로 슬라이스를 보여주기 때문.

## 사진 영역(크롭)
사진을 고르면 `사진 영역 설정` 창이 자동으로 열린다. **드래그 = 이동**, **핀치 또는 -/+ = 확대·축소(100~400%)**, `초기화`로 중앙·100%. 이후 `영역` 버튼으로 다시 열 수 있다.
값은 `photoZoom / photoDx / photoDy`로 저장되어 잠금 화면과 `선택한 사진을 홈 화면에 적용` 양쪽에 동일하게 쓰인다.

## 크기 조절 방식
가이드 사각형은 렌더러와 동일한 변환을 쓴다: 캔버스 중심 기준 `scale(sx, sy)` + 오프셋.
- 가로로 늘리면 **카드 폭만** 커지고 글자 크기는 그대로다 → 날짜 칸이 넓어져 제목이 더 보인다
- 세로로 늘리면 카드 높이(주 간 여백)가 커진다

## 빌드
```powershell
pwsh -File build.ps1            # build\calwall.apk
pwsh -File build.ps1 -Install   # 설치 + 실행
```
Gradle 없이 aapt2 → javac → d8 → zipalign → apksigner 순서로 빌드한다 (SDK build-tools 36 사용).

## 조절 항목
- **캘린더 투명도**: 글자·막대 등 캘린더 내용 전체 (0–100%, 기본 100%)
- **카드 배경**: 흰 카드의 불투명도 (0–100%, 기본 94%)
- **위치**: 캘린더 블록을 드래그
- **가로 크기**: 오른쪽 가운데 손잡이 / **세로 크기**: 아래 가운데 손잡이 / **둘 다**: 오른쪽 아래 모서리 손잡이 (각 40~200%, 가로·세로 독립)
- `위치·크기 초기화`로 100% × 100%, 중앙 복원

## 글자 색 지정
`요일 글자` / `날짜` / `일정 글자` 각각 **자동**(테마 기본값), 6가지 프리셋, 또는 **`+` 버튼으로 직접 지정** — HSV 색상 휠 + 밝기 바 + 헥스 입력(`#RRGGBB`) + RGB 값 표시. `자동`이면 주말은 빨강·파랑으로 구분되고, 색을 직접 고르면 모든 날짜에 그 색이 적용된다. 오늘 표시(테두리 원)는 강조색을 그대로 쓴다.

## 사용
1. `사진 선택`으로 배경 사진 지정 (선택 안 하면 그라데이션)
2. `잠금 화면에 적용`
3. 잠금 화면에서 확인 — 다음 갱신은 자동으로 00:05에

## 요구 사항
- Android 12 (API 31) 이상
- 빌드: JDK 21 + Android SDK build-tools 36 (`aapt2`, `d8`, `zipalign`, `apksigner`)

## 검증한 것
- 백그라운드에서 알람 → 렌더 → 적용 동작 (앱이 백그라운드일 때 실측)
- 적용 후 `dumpsys alarm`에 `dev.dsh.calwall.ALARM` 00:05 등록 확인

> 개인용으로 만든 앱입니다. 빌드 산출물(APK)과 서명 키는 저장소에 포함하지 않습니다.
